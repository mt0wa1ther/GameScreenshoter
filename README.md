# 🎮 Game Screenshoter

Автоматический захват игрового экрана для **GTA 5 / Majestic RP**.

Приложение делает скриншоты окна игры, сохраняет их с датой и временем,
ведёт прозрачный таймер до следующего снимка прямо поверх игры.

![Version](https://img.shields.io/badge/version-1.0.2-blue)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)
![License](https://img.shields.io/badge/license-Free%20for%20personal%20use-green)

## ✨ Возможности

- 📸 **Ручной скриншот** — по кнопке или **настраиваемому хоткею**
- ⏰ **Авто-снимок** каждые 21 минуту, только когда запущена игра
- 📺 **Прозрачный оверлей-таймер** поверх всех окон
- 🎮 **Автозахват окна** GTA 5 / Majestic (без рамок и панели задач)
- 📁 **Умное хранение** — папки с датой, отдельная папка для ручных снимков
- 🧹 **Автоочистка** старых папок (старше 14 дней)
- 🖥 **Иконка в трее** — быстрое меню с действиями
- 🌙 **Современный тёмный интерфейс**

## 📥 Установка

### Вариант 1. Установщик (рекомендуется)

1. Скачайте `GameScreenshoter_Setup_v1.0.0.exe` из раздела [Releases](../../releases)
2. Запустите установщик
3. Примите условия лицензии
4. Выберите папку и нужные ярлыки
5. Готово! Приложение появится на рабочем столе

### Вариант 2. Портативная версия

1. Скачайте `GameScreenshoter_Portable_v1.0.0.zip` из [Releases](../../releases)
2. Распакуйте в любую папку
3. Запустите `GameScreenshoter.exe`

Портативная версия не требует установки.

## ⚙️ Использование

| Действие | Как сделать |
|---|---|
| Скриншот | Кнопка **📸 Сделать скриншот** или **ваш хоткей** |
| Изменить хоткей | Кнопка **Изменить** в блоке «Хоткей скриншота» |
| Автоснимки | Кнопка **▶ Авто** (включается автоматически при запуске игры) |
| Оверлей | Кнопка **📺 Оверлей** или правый клик по иконке в трее |
| Открыть папку | Кнопка **📂 Папка** |
| Свернуть в трей | Кнопка **🗕 В трей** или крестик окна |

## 📁 Где хранятся скриншоты


Файлы сортируются по имени = по времени. Ручные и авто — в разных папках.

## ⚠️ Важно про антивирус

Некоторые антивирусы (в частности Windows Defender) могут ругаться
на Python-приложения, упакованные через PyInstaller. Это **ложное
срабатывание**. Если файл был удалён — добавьте папку установки
в исключения.

## 🎮 GTA 5 / Majestic — рекомендуемый режим

Для корректного захвата окна игра должна быть в режиме
**"Оконный без рамки"** (Windowed Borderless). В эксклюзивном
полноэкранном режиме снимок может получиться чёрным.

## 🔒 Конфиденциальность

Приложение **не собирает** и **не передаёт** никаких данных.
Все файлы хранятся локально. Приложение **не имеет доступа
к интернету**.
